Política de Privacidade

Última atualização: 8 de outubro de 2026.

O Meu Treino Pró foi desenvolvido para permitir a organização, o registro e o acompanhamento de treinos de forma simples, preservando a privacidade do usuário.

Dados do usuário

O Meu Treino Pró não exige a criação de uma conta para utilização do aplicativo.

As informações de treino registradas pelo usuário são utilizadas para fornecer as funcionalidades do próprio aplicativo.

Armazenamento

Os dados de treino são armazenados localmente no dispositivo. O Meu Treino Pró não utiliza um servidor próprio para armazenar os registros pessoais de treino do usuário.

Compartilhamento de dados

O Meu Treino Pró não vende informações pessoais e não utiliza os registros de treino do usuário para publicidade direcionada.

Importação e exportação

O aplicativo pode oferecer recursos para importar ou exportar informações de treino. O usuário controla quando utiliza esses recursos e é responsável pelo destino dos arquivos que decidir compartilhar ou armazenar fora do aplicativo.

Apple Watch

O Meu Treino Pró pode disponibilizar funcionalidades integradas ao Apple Watch para auxiliar na utilização e no acompanhamento do treino.

Serviços de terceiros

O Meu Treino Pró não utiliza os dados pessoais de treino para fins de publicidade ou comercialização de informações.

Alterações nesta política

Esta Política de Privacidade poderá ser atualizada caso as funcionalidades ou práticas de tratamento de dados do aplicativo sejam modificadas. A versão atualizada será disponibilizada nesta página.
