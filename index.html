Política de Privacidade

Última atualização: 23 de outubro de 2026.

O Meu Treino Pró foi desenvolvido para permitir a organização, o registro e o acompanhamento de treinos de forma simples, preservando a privacidade do usuário.

Dados do usuário

O Meu Treino Pró não exige a criação de uma conta para utilização do aplicativo. As informações de treino registradas pelo usuário são utilizadas para fornecer as funcionalidades do próprio aplicativo.

Armazenamento

Os dados de treino são armazenados localmente no dispositivo. O Meu Treino Pró não utiliza um servidor próprio para armazenar os registros pessoais de treino do usuário.

Compartilhamento de dados

O Meu Treino Pró não vende informações pessoais e não utiliza os registros de treino do usuário para publicidade direcionada.

Backup e restauração

O aplicativo permite que o usuário crie e restaure, por sua própria iniciativa, cópias de backup dos seus dados de treino. Ao criar um backup, o usuário escolhe o destino do arquivo usando o seletor nativo do iOS (por exemplo, iCloud Drive, Arquivos ou AirDrop); o desenvolvedor do Meu Treino Pró nunca recebe nem tem acesso a esse arquivo. Se o destino escolhido for um serviço de terceiros, o armazenamento desse arquivo passa a estar sujeito aos termos e à política de privacidade desse serviço. A restauração é feita localmente, a partir de um arquivo escolhido pelo próprio usuário.

Imagens de exercícios

O usuário pode associar fotos pessoais a exercícios cadastrados no aplicativo. Essas imagens são armazenadas apenas localmente no dispositivo e não fazem parte do arquivo de backup do banco de dados: criar ou restaurar um backup não inclui essas fotos.

Apple Watch

O Meu Treino Pró pode disponibilizar funcionalidades integradas ao Apple Watch para auxiliar na utilização e no acompanhamento do treino. Essa integração usa os recursos de comunicação entre iPhone e Apple Watch oferecidos pela própria Apple (WatchConnectivity); os dados de treino trocados entre os dois dispositivos continuam armazenados localmente, nunca em um servidor do desenvolvedor.

Apple Saúde

O Meu Treino Pró pode solicitar permissão para registrar sessões de treino no Apple Saúde, para que também apareçam no app Saúde/Fitness do usuário. O aplicativo solicita apenas permissão de escrita: não lê o histórico de saúde do usuário no Apple Saúde, e não coleta, armazena nem exibe dentro do Meu Treino Pró dados de calorias ou de frequência cardíaca provenientes do Apple Saúde.

Exclusão de dados

O usuário pode excluir registros individuais diretamente no aplicativo. Ao desinstalar o Meu Treino Pró, os dados armazenados localmente pelo aplicativo são removidos, conforme o comportamento padrão do iOS. Arquivos de backup já exportados anteriormente para fora do aplicativo (por exemplo, para o iCloud Drive ou para o app Arquivos) não são apagados automaticamente nem pela exclusão de dados dentro do aplicativo, nem pela desinstalação — a exclusão desses arquivos é de responsabilidade do usuário.

Publicidade e rastreamento

O Meu Treino Pró não exibe publicidade e não utiliza serviços de rastreamento ou de análise de terceiros. Os dados pessoais de treino do usuário não são utilizados para fins de publicidade ou comercialização de informações.

Alterações nesta política

Esta Política de Privacidade poderá ser atualizada caso as funcionalidades ou práticas de tratamento de dados do aplicativo sejam modificadas. A versão atualizada será disponibilizada nesta página.
